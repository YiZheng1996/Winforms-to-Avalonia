## 2. 阶段 1 开放问题的临时假设（仅用于骨架，不视为最终规格）

- 任务编号：自动生成（Task-YYYYMMDD-序号），后续按确认调整。
- 产品标识：第一版通用字段为 产品编号、批次号、工位号、备注（均可空，任务创建时校验
  至少一项），后续按确认调整。
- 参数类型：Boolean/Integer/Decimal/Text/Enum；范围/精度/枚举在 ParameterDefinition 上。
- 配方版本号：型号内正整数自增；发布/停用记录操作人与时间。
- 内置角色：Administrator（全部权限）、Operator（执行相关）、Maintenance（设备/校准），
  具体默认权限矩阵待阶段 1 确认。
- 项点结果：第一版仅保存摘要值/结论文本，不做高频曲线存储。

## 3. 已实现边界（阶段 2 内）

- 写入安全链 DeviceWritePipeline：
  权限 → 模式（Hardware 必须真实运行时；Simulation 只写仿真状态）→ 连接与点位质量 →
  活动任务/运行状态 → 业务联锁 → 风险确认 → 写入 → 回读（Hardware）→ 审计。
- DeviceMode 是启动配置；切换需要维护权限 + 无活动任务 + 重新初始化。
- 配置无效进入 Faulted 状态并显示诊断，不静默回退默认值，不切换 Simulation。
