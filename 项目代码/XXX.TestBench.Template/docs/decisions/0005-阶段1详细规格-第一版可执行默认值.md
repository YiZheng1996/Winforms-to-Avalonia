## 3. P0 页面规格要点

### 3.1 登录
- 用户名 + 密码；失败提示；连续 5 次失败锁定 5 分钟（显示锁定时间）；must_change_password 时强制改密（原密码 + 新密码 ≥8 位且不同）。
- 登录页不提供设备模式选择。

### 3.2 应用外壳
- 顶栏：系统名称、设备模式徽标（Simulation/Hardware）、连接状态、登录用户、退出。
- 左侧导航：按权限过滤页面。
- 底部状态：数据库路径、设备、版本。
- 全局故障横幅：配置无效时显示诊断（已有）。

### 3.3 任务管理
- 列表（任务编号、产品型号、配方版本、状态、产品编号、创建时间）。
- 新建：选择产品类型→型号→已发布配方；填写产品编号/批次/工位/备注；校验至少一项。
- 取消：Draft/Ready 可取消。

### 3.4 试验执行
- 选择 Ready 任务 → 预检（设备健康）→ 启动 → 项点列表逐项“执行”→ 全部完成后“结束”。
- 显示记录状态、项点结果（判定/摘要/说明）；失败项点结束为失败。

## 4. P1/P2 页面要点
- 配方中心：Tab 页（产品类型/产品型号/试验项定义/参数定义/配方版本/配方编辑器），写操作权限 Manage*。
- 数据与报表：记录查询列表，已完成记录可“生成报表”，显示报表记录（路径/状态）。
- 运行总览：模式、设备健康、当前活动任务、快捷入口。
- 工艺监控：只读实时点位表（Simulation 值）；手动动作经 DeviceWritePipeline。
- 设备与校准：设备状态、点位列表；写入走安全链。
- 系统管理：用户/角色只读列表（第一版）；写管理待后续。
- 日志诊断：audit_logs 只读列表 + 导出日志文件路径。

## 5. 验收口径（对应总体方案第 14 节 1-11 项，第 12 项 Windows 本机）
- 新主线独立构建；登录/权限/SQLite 重启回读；产品/配方全链路；任务只选已发布匹配配方；
  Simulation 闭环带仿真标识；Hardware 失败阻断不回退；写入走安全链；记录/结果不可静默修改；
  Excel 只做输出；P0/P1 双分辨率无关键遮挡；各层测试通过；Windows/Simulation 状态分别标注。
