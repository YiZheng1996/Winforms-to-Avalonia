   ShellViewModel.NavigateAsync 对页面 LoadAsync 异常兜底（PageViewModel.ReportError → StatusMessage）。
2. 试验执行页：结束后按实际记录状态显示（失败不再硬编码 Completed）。

4. RecipeService.SetItemOrderAsync：配方项点顺序调整（占用顺序时交换），支持编辑器后续接入。
5. TaskService.UpdateIdentityAsync：草稿任务可编辑产品标识（至少一项；非草稿拒绝）。
