# ADR-0010：设备点位独立为左侧导航菜单页

- 日期：2026-09-03
- 状态：已接受
- 目标项目：XXX.TestBench.Template

## 背景

参数管理页曾把“设备点位”作为第 6 个标签页嵌入（`ParameterManagementView`）。
设备点位维护的是 PLC/仿真点位协议、地址、量程与写入安全属性，与参数管理中的产品/试验主数据职责不同，
且编辑入口受 `ManageDevices` 权限控制，与“设备与校准”同权限域。

## 决策

1. 从 `ParameterManagementView` 删除“设备点位”标签页；参数管理页固定为 5 个标签：
   产品类型 / 产品型号 / 试验项点 / 项点配置 / 试验参数。
2. “设备点位”作为独立菜单页加入左侧导航，位于“设备与校准”之后，与设备权限域保持一致：
   - 导航项：`设备点位`，权限 `PermissionCode.ManageDevices`；
   - 页面：`DevicePointManagementView` + `DevicePointManagementViewModel`，复用原有新增/编辑/删除/导入能力。
3. 调整“试验参数”标签顺序至参数管理最后一个标签，页面打开默认仍为“产品类型”。
4. 只读展示不对无 `ManageDevices` 权限的操作员开放（Operator 角色不授予 `ManageDevices`）。
5. 页面提供“下载导入模板”和“按模板导入”入口；模板列名、列顺序和数据工作表名称固定为中文格式，导入与模板共用同一份格式定义。

## 影响

- Administrator 左侧导航由 8 项变为 9 项；Maintenance 可见并管理“设备点位”；Operator 不可见。
- 参数管理页 `ParameterManagementViewModel` 不再持有 `DevicePointTab`，标签索引相应调整。
- 运行时点位加载与写入安全门不变；仍由 `points.json` 配置副本 + `DeviceWritePipeline` 管理。

## 不做

- 不改变设备点位数据模型、原子保存或运行时重载逻辑；导入表头校验升级为固定中文模板格式。
- 不把“设备点位”并入“设备与校准”页；保持单页独立管理。
