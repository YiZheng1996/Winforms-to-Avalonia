# W08 型号报表资源管理

日期：2026-11-16
状态：已增加型号级产品判定/过程报告资源管理、准备指导图文包导入/校验/摘要绑定及管理窗口只读预览；尚未配置真实型号资源，准备指导确认门尚未接入试验操作页。

## 本轮实现

- 在现有 v9 `model_resource_profiles` 表上增加实体、仓储和型号资源配置领域合同，沿用 `row_version` 做并发条件更新，没有修改 schema 版本。
- 新增 `ModelResourceService`。管理员可为型号导入产品判定模板/映射和过程报告模板/映射；产品映射必须有 Excel 总判定目标并支持自动试验，过程映射不得有产品结论且须支持自动与单项范围。
- 新增参数管理中的“报表资源”入口和文件选择窗口，模板只接受 `.xlsx`，映射只接受符合 V1 合同的 UTF-8 JSON。首次配置须先有产品判定模板，之后可补过程报告资源。
- 每次导入生成新的资源键，文件内容由 `FileModelResourceStore` 按 SHA-256 不可变保存。读取前校验资源键唯一对应一个摘要并复核对象内容；资源配置及审计记录在同一数据库工作单元提交。
- 报表输入资源解析时重新读取映射并核验 Purpose/RunScope，防止配置损坏或跨用途引用。
- 型号资源窗口新增准备指导 ZIP 导入。包内为无 BOM UTF-8 `guidance.json` 和 `images/` 下 PNG/JPEG 图片；最多 32 MB 压缩文件、64 MB 解压内容、200 个步骤、64 张图片。校验 schema 版本、步骤字段及唯一 ID、图片路径/扩展名/文件签名和图片引用集合，不接受未引用文件或目录穿越路径。
- 导入的准备指导包按新的不可变资源键和 SHA-256 摘要绑定到型号配置；`GetReportResourcesAsync` 读取资源时会重新校验包内容。当前只完成资源配置与校验，步骤图文预览尚未接入试验页，必确认项交互和准备门禁仍未实现。
- 已保存指导可从型号资源窗口只读预览步骤文本、图片、必确认标记及资源摘要；预览读取时再次校验摘要和包内容。预览不记录确认，也不改变试验入口停用状态。
