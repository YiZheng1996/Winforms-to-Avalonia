1. 参数字段由项目代码固定，不做动态参数定义表、不做键值型参数表。
2. 不新建配方管理、配方编辑器、运行时无代码设计器（现有配方主链本次不动，其去留另行单独确认）。

## 5. Core 新增模型与验证器

新增文件：`src\XXX.TestBench.Core\Domain\TestParameters\TestParameterModels.cs`

```csharp
namespace XXX.TestBench.Core.Domain.TestParameters;

/// <summary>自动试验最终使用的强类型参数。</summary>
public sealed record EffectiveTestParameters
{
    public required int ProductTypeId { get; init; }
    public required int ProductModelId { get; init; }
    public required int TestTimeSeconds { get; init; }
    public required double TestVoltageV { get; init; }
    public required double ProtectCurrentMa { get; init; }
}

public sealed record TestParameterValidationResult(bool IsValid, string Error)
{
    public static TestParameterValidationResult Success() => new(true, string.Empty);
    public static TestParameterValidationResult Fail(string error) => new(false, error);
}

public static class TestParameterValidator
{
    public static TestParameterValidationResult Validate(EffectiveTestParameters value)
    {
        if (value.ProductTypeId <= 0) return TestParameterValidationResult.Fail("未选择有效的产品类型。");
        if (value.ProductModelId <= 0) return TestParameterValidationResult.Fail("未选择有效的产品型号。");
        if (value.TestTimeSeconds is < 1 or > 3600) return TestParameterValidationResult.Fail("试验时间必须在 1～3600 s 之间。");
        if (value.TestVoltageV is <= 0 or > 5000) return TestParameterValidationResult.Fail("试验电压必须大于 0 且不超过 5000 V。");
        if (value.ProtectCurrentMa is <= 0 or > 1000) return TestParameterValidationResult.Fail("保护电流必须大于 0 且不超过 1000 mA。");
        return TestParameterValidationResult.Success();
    }
}
```

约束：

- UI 保存前和自动试验启动前必须调用同一个 `TestParameterValidator`，不允许各写一套范围判断。
- `EffectiveTestParameters` 只使用数值类型，不保存带单位字符串。

新增服务：`src\XXX.TestBench.Core\Application\TestParameterService.cs`

- 构造注入：`ITestParameterRepository`、`IProductRepository`、`IClock`、`IAuditLog`。
- 编辑权限复用现有 `PermissionCode.ManageTestDefinitions`（不新增权限码）。
- `LoadEffectiveAsync(int productModelId, CancellationToken ct)`：
  1. 校验 `productModelId > 0`；
  2. 用 `IProductRepository.GetModelAsync` 取型号，再用 `GetTypeAsync` 取类型，确保 ID 真实存在；

- `SaveProjectAsync(UserContext actor, int testTimeSeconds, CancellationToken ct)`：校验权限 → 按 `TestParameterValidator` 的字段规则校验 → 写 `project_test_parameters` → 写审计 `TestParameterSaved`。
- `SaveProductAsync(...)`：校验权限 → 校验产品类型与产品型号匹配 → 字段规则校验 → 写 `product_test_parameters` → 写审计。
