# 设备点位管理与导入

## 作用

设备点位是运行时读取数据的来源，和“试验项点”不是同一个概念：

- 设备点位：维护协议、地址、数据类型、单位、量程、可写和风险等级。
- 试验项点：维护产品类型下的试验名称、编译期执行器和执行顺序。
- 试验参数：维护项目、产品类型和产品型号级的业务参数。

当前模板仍以 `config/points.json` 作为运行时兼容来源。左侧导航“设备点位”页（独立于参数管理，位于“设备与校准”之后）支持手工新增、编辑、删除、下载导入模板，以及按固定格式导入 `.xlsx` / `.csv`。

## 导入列

页面“下载导入模板”生成 `设备点位导入模板.xlsx`，包含“点位模板”和“填写说明”两个工作表。导入时必须使用该模板：第一个工作表名称必须为“点位模板”，第1行必须严格保持以下中文列名和顺序，不允许使用英文列名、增删列或调换顺序：

`点位编码`、`点位名称`、`协议`、`地址`、`数据类型`、`单位`、`原始下限`、`原始上限`、`工程下限`、`工程上限`、`可写`、`风险等级`、`启用`、`说明`。

必填数据：点位编码、协议、地址、数据类型。`可写` 和 `启用` 填写“是/否”，`风险等级`填写“普通/高风险”；留空时分别按“否”“是”“普通”处理。四个量程列必须全部填写或全部留空。Excel 和 CSV 都必须使用同一套中文表头；CSV 示例文件：`设备点位导入模板.csv`。

导入器会清理表头首尾空格和 UTF-8 BOM，但不会兼容英文表头或其他列名变体。

## 保存规则

导入会整体替换当前点位目录，但在保存前完成必填字段、重复编码、协议/地址重复、量程完整性和上下限关系校验。校验失败时不保存；保存使用临时文件、`.bak` 备份和原子替换，随后重载当前设备运行时。

存在活动试验时禁止修改点位。点位配置只声明数据，不会通过 Excel/CSV 生成或执行任意代码；真实 Hardware 通信仍需对应设备适配器和现场验收。
